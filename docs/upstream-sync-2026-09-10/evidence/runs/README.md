# 执行证据约定

为每个执行单元建立唯一目录，例如 B07-001。这个目录当前只有约定文件，没有新的正式合并测试结果。

每次运行保存一个 manifest.json 和对应日志，至少包含：

- 阶段/单元 ID、命令原文、工作目录、开始/结束时间。
- 被测代码提交的完整 SHA、Go/Bun/Node/操作系统及数据库版本。
- 退出码、通过/失败/跳过数量，哪些保护能力及上游行为得到验证。
- 日志相对于计划目录的路径、必要的浏览器截图或脱敏供应商响应。
- 失败/中断原因、下一步；进程没有正常结束则不给通过状态。

manual 验收记录操作步骤、预期、实际与证据，不伪造命令退出码。真实请求凭据、支付数据、完整 DSN 和敏感请求体不进入 Git。

state.gates 和各台账的 evidence 数组填相对于本计划目录的实际文件路径。最终复核必须针对 last_verified_code_commit；历史早期通过不能替代最终复核。

通过日志保存后再标记 verified。工具检查文件存在与记录一致性；执行者仍须检查日志内容和真实行为。
