# new-api 绘图游乐场

游乐场包含两个子页面：`/playground/chat` 保留原有聊天功能，`/playground/drawing` 提供绘图画布。原来的 `/playground` 地址会跳转到聊天页。

绘图沿用登录账号、可用分组和额度，通过服务端的 `/pg/images/generations` 与 `/pg/images/edits` 接入现有图片中转流程。模型分发、模型映射、请求校验、额度结算和用量日志复用现有实现。页面无需填写上游密钥。

## 绘图与编辑

- 输入提示词、选择分组和绘图模型，设置数量、尺寸与画质后生成图片。模型输入框支持可用模型列表和自定义模型别名。
- GPT Image 参数包括背景、PNG/JPEG/WebP 输出、压缩率、内容审核、流式预览及预览图片数量；编辑时可设置输入保真度。
- DALL·E 模型提供响应格式设置；DALL·E 3 另有风格设置，每次生成一张图片，并禁用图片编辑。
- 编辑模式支持上传参考图，或将画布上的图片设为参考。GPT Image 最多使用 16 张参考图，DALL·E 2 使用一张参考图。
- 可上传 PNG 蒙版或用画笔绘制蒙版。蒙版对应第一张参考图，尺寸必须一致，透明区域表示需要编辑的区域。
- 参数是否可用取决于实际渠道与模型能力。自定义模型别名采用 GPT Image 参数选项。

画布支持图片拖动、缩放、框选、调整卡片大小、自动排列、撤销和重做。可通过上传、拖放或粘贴添加图片，预览及下载生成结果，复用已有图片的提示词和参数。编辑结果与参考图片通过连线关联。

## 保存与迁移

画布保存在浏览器 IndexedDB，按账号 ID 隔离。每个账号在当前浏览器保存一个画布，包括图片、位置、视图、参数、参考图选择及蒙版。可导出 JSON 文件备份，再在另一个浏览器中导入；导入与清空需要确认。

画布最多保存 500 张图片，单个导入文件上限为 200 MB。上传参考图支持 PNG、JPEG 和 WebP，单张上限为 50 MB。DALL·E 2 编辑需要小于 4 MB 的正方形 PNG，蒙版也必须小于 4 MB。浏览器可用存储空间因设备而异。

使用 URL 响应格式时，图片链接的有效期由上游决定；需长期保留的结果可下载为图片。页面关闭后，在途请求不会继续作为后台任务运行；重新打开时未完成的卡片显示为已停止。

## 部署

前后端需要一起更新，沿用项目现有部署流程。此功能无需新增环境变量或数据库迁移。

部署后用实际渠道验证文生图、参考图编辑、蒙版、流式结果，以及所选分组对应的用量日志和额度变化。前端生产构建本身不验证上游模型能力或真实扣费。
